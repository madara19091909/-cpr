# مزرعتي — MVP

واجهة أولية عربية للعبة مزارع شخصية مع زيارة الأصدقاء والتنافس. المشروع منظم كنقطة بداية قابلة للتطوير، وليس نسخة مكتملة أو مختبرة على جهاز فعلي.

## المتطلبات
- Flutter SDK حديث
- مشروع Supabase (خطة الاستضافة المجانية قد تتغير حسب شروط المزود)
- إعداد Google OAuth داخل Supabase ولوحة Google Cloud

## التشغيل محلياً
1. فك ضغط الأرشيف.
2. من مجلد المشروع:
   ```bash
   flutter pub get
   ```
3. أنشئ مشروع Supabase ثم نفّذ `supabase/schema.sql` من SQL Editor.
4. انسخ `lib/config/app_config.example.dart` إلى `lib/config/app_config.dart` وضع عنوان مشروع Supabase و anon key.
5. في `lib/main.dart` أزل التعليق عن تهيئة Supabase (أو اتبع التعليقات داخل الملف).
6. شغّل:
   ```bash
   flutter run
   ```

> لا تضع `service_role` key داخل تطبيق Flutter أبداً. استخدم anon key فقط مع سياسات RLS، واجعل التحقق من الرصيد والشراء على الخادم.

## المصادقة
يدعم تصميم شاشة الدخول البريد/كلمة المرور وGoogle عبر Supabase Auth. تسجيل Google يحتاج ضبط OAuth redirect URL حسب معرف التطبيق وإعدادات Supabase. لا يمكن تأكيد عمل تسجيل الدخول قبل ضبط هذه القيم وتجربتها.

## ما يتضمنه الإصدار الأولي
- واجهة عربية RTL للمزرعة.
- متجر بذور وأسعارها ومستويات فتحها حسب القائمة المقدمة.
- متجر الحيوانات الإنتاجية والأليفة.
- متجر الأدوات وأسعار العملات الممتازة.
- شاشة دخول/إنشاء حساب أولية.
- مخطط قاعدة بيانات للعلاقات والمزارع والمخزون والزيارات والمعاملات.
- دوال شراء مبدئية تتحقق من الرصيد والمستوى على قاعدة البيانات.

## ما لم يُنفّذ بعد
- رسومات لعبة نهائية أو أنيميشن متكامل.
- نظام نمو زمني متصل وإنتاج الحيوانات.
- نظام الأصدقاء والزيارات الكامل داخل التطبيق.
- بناء APK واختباره على جهاز فعلي.
- إعداد Google OAuth الفعلي وربط مفاتيح مشروع Supabase.
